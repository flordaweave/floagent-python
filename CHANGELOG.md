# Changelog

All notable changes to this project will be documented in this file.

## 0.1.1 - 2026-08-16

- Allow Streamlit apps to customize the user-facing authentication service name.

## 0.1.0 - 2026-08-16

- Add a dependency-free FloAgent handoff and token-refresh client.
- Add typed session and service-endpoint models.
- Add a Streamlit adapter for Session State, safe redirects, token cleanup,
  session refresh, and logout.
- Require an explicit allowlist for server-side API base URL discovery.
