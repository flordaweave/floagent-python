# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form in this repository's
Security tab. Do not disclose suspected vulnerabilities in a public issue.

Include the affected SDK version, the relevant integration, reproduction
steps, and the expected security impact. Never include live handoff, access,
or refresh tokens in a report.

## Supported versions

Until the SDK reaches 1.0, security fixes are released from the latest minor
version. Consumers should pin a compatible version and keep it updated.
